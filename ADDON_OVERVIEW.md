The `.mcaddon` is a container holding two separate ZIP archives: a Behavior Pack (BP) and a Resource Pack (RP). The BP contains gameplay logic such as entity definitions, items, functions, scripts, animation controllers, and related data. The RP contains client-side presentation data such as entity/render definitions, animations, animation controllers, models, textures, sounds, and language resources.

The source dump preserves each exported file's archive name and internal path in a header. Search by filename, directory, entity identifier, item identifier, function name, or script symbol. Use `FILE_INDEX.csv` to locate binary assets and non-text files that are not embedded in the text dump.

This overview is based on the package's directory structure and file extensions; it does not claim that every feature or dependency has been fully reverse-engineered.
